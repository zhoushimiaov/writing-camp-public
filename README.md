# ✒️ 写作小能手训练营

**只提问，不代笔** —— 给三到九年级孩子的写作训练小工具，每天 15 分钟。纯本地运行：不安装、不注册、不联网也能用，所有数据只存在自己的浏览器里。

## 它解决什么问题

很多孩子不是"不会写"，而是**不知道写什么**和**不敢下笔**。这个程序只做一件事：用问题把孩子肚子里的话"问"出来——程序从头到尾不会替孩子写一个字。

- **🖋 写作教练**（核心）：四步流程——选题目 → 问答攒"弹药"（只提问）→ 15 分钟自由写（弹药库随取随用）→ 交卷自检（不打分不改错）。教练是一位戴眼镜的小铅笔人「笔笔」，全程陪伴。
- **🎒 训练营**：素材本（三个词也算一条）、五感放大器（把一样东西放大成细节卡）、口述挑战（18 张卡，先说后写）、仿写工坊（23 个好句子的骨架）
- **📚 作品集**：选"金句"、生成作品卡、复制发家庭群、打印
- **🏆 成就图鉴**：12 张成就卡，每张是一位专属卡通小伙伴（小笔星、书宝宝、火苗仔、月亮兔、侦探喵……），解锁时弹卡庆祝，收集欲拉满
- **🎨 专属配色**：每个孩子可以从 6 套马卡龙主题（樱花粉 / 薄荷糖 / 薰衣草 / 柠檬苏打 / 天空云 / 蜜桃奶昔）里选自己的，切换孩子时整个界面跟着换心情
- **👪 家长角**：孩子近况、每周节奏表、数据备份
- **游戏化**：XP、科举段位（童生 → 秀才 → 举人 → … → 大文豪）、每日任务
- **📖 教材同步**：统编版**三到九年级**全部单元习作 / 写作单元——初中含议论、说明、演讲稿等文体的专属提问链

## 三种用法（按省事程度排序）

### ① 直接在线用（推荐）

打开 **<https://writing.shimiao.work/>** 就能用。

iPad / 手机：浏览器打开 → 分享 → **添加到主屏幕**，之后从图标点开，全屏运行就像装了个 App。

### ② 下载单文件版（不想联网）

下载本仓库里的 **`写作小能手训练营-单文件版.html`**，双击即可使用，也可以通过微信 / AirDrop 发到 iPad 的「文件」里打开。

> ⚠️ iOS 对本地文件的存储不稳定，作品可能不保存，应急体验可以，正式使用请用 ① 或 ③。

### ③ 自己部署（一劳永逸）

纯静态页面，任何静态托管都能用，推荐 Cloudflare Pages（免费、自动 HTTPS、PWA 完整生效）：

```bash
git clone https://github.com/zhoushimiaov/writing-camp-public.git
cd writing-camp-public
python build_dist.py        # 生成 dist/ 部署包
npx wrangler pages deploy dist --project-name=你的名字   # 需要先 npx wrangler login
```

或者打开 dash.cloudflare.com → Workers & Pages → Create → Pages → **Upload assets**，把 `dist` 文件夹里的内容拖进去。

局域网用法（不想上公网）：电脑上运行 `python server.py`，iPad 连同一个 Wi-Fi 用 Safari 打开窗口里给出的网址即可。

## 不爱打字的孩子也能完整使用

1. **🔊 念给我听**：教练的问题、口述卡都有朗读按钮，浏览器自带，不联网。
2. **🎙️ 说话变成字**：iPad 键盘右下角的 🎤 听写键任何情况下都能用；页面内的「🎙️ 说」按钮在 Edge/Safari 可用（iOS 需要 https 网址）。
3. **📷 拍照认字**：孩子手写在纸上，拍张照就变成电子文本放进文章。需要家长在「家长角」配置一个免费 AI Key（智谱 / Agnes / Gemini 三选一），**程序只逐字转录，不会替孩子改一个字**。

## 隐私说明

- 所有数据（作品、素材、XP）只保存在**本机浏览器**的 localStorage 里，没有服务器、没有账号、没有统计代码。
- AI 识别 / 批改用的是家长自己注册的 API Key，密钥只存本机，**导出的备份文件不含密钥**。
- 换设备用「家长角 → 导出备份 / 导入备份」互传。

## 适合谁

- 三到九年级的孩子（小学 + 初中都覆盖；题目按统编版教材整理，初中含议论文、说明文、演讲稿）
- 上海家庭注意：上海是五四学制，六年级（预备班）用的正是全国六年级教材内容，七~九年级对应全国统编初中，直接选对应年级就行
- 一个孩子到四个孩子都行：**首次打开自己给孩子建档案**，名字、年级、头像、专属配色随时可改
- 认同「先写完，再写好」的家庭

## 每周节奏（每天 15 分钟）

| 星期 | 任务 | 说明 |
|---|---|---|
| 周一 | 👝 素材日（轻量热身） | 往素材本存 3 条小碎片（三个词也算） |
| 周二 | 🎙️ 口述日（轻量热身） | 抽一张口述卡，大声说满 1 分钟 |
| 周三 | 🕵️ 五感日 | 用五感放大器做 1 张细节卡 |
| 周四 | ✍️ 仿写日 | 照着好句子仿写 2 句 |
| 周五 | 📝 小练笔日（本周压轴） | 跟着写作教练完成一篇小练笔 |
| 周六 | 📣 真实读者日 | 把作品分享到家庭群 |
| 周日 | 🌟 回顾日 | 把本周金句读给家人听 |

任务顺序只是建议，孩子想练哪项随时可以练，当天完成就能点亮连击 🔥。

## 给家长的三条提醒（程序替你记住）

1. **不盯着写** —— 不坐在旁边看，更不要写一个字纠一个字。
2. **夸具体的点** —— "这个动词用得准"比"写得不错"有用一百倍。
3. **先写完，再写好** —— 这个阶段唯一的目标是"写完"，能交卷就是赢。

## 目录结构与二次开发

```
index.html / style.css / js/   纯 vanilla HTML/CSS/JS，无框架、无构建、无依赖
server.py                      局域网服务器（Windows 双击「在iPad上打开（局域网）.bat」）
build_singlefile.py            把全部代码 + 子集字体打包成单文件 HTML（需要 fontTools）
build_dist.py                  生成 Cloudflare Pages 部署包 dist/
fonts/                         霞鹜文楷（LXGW WenKai）woff2 + 授权文本
icons/                         PWA 图标（make_icons.py 可重新生成）
```
